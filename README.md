# WSNotify

[![Go Report Card](https://goreportcard.com/badge/github.com/yourusername/wsnotify)](https://goreportcard.com/report/github.com/yourusername/wsnotify)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

WSNotify is a production‑ready WebSocket notification service written in Go. 
Clients connect via WebSocket and receive real‑time messages published through a simple HTTP API.

## Features

- **Scalable WebSocket hub** – thread‑safe client management.
- **HTTP JSON API** to broadcast notifications.
- Structured logging with Logrus.
- Environment‑based configuration (`.env` support).
- Comprehensive unit tests.
- Clean, modular code following Go best practices.
